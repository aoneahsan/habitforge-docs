# Morning routine builder and daily checklist

**The HabitForge Morning Routine page lets you build one ordered list of morning tasks — each with a name and a time estimate in minutes — and then run it as today's checklist.** You design the routine once in edit mode, and every day the page shows it back to you as a sequence of numbered steps you tick off in order. As you check tasks, a live counter tracks how many of the steps are done and how many minutes you've completed out of the routine's total. Finish all of them and the page celebrates the win. It's the difference between "I should have a morning routine" and actually having one you execute.

## Use cases

### Designing a repeatable morning

Instead of improvising every morning, you build the sequence once: `Drink water` (1 min), `Stretch` (10 min), `Journal` (5 min), `Plan the day` (5 min). The routine remembers the order and the time estimates, so each morning is a checklist rather than a decision.

### Running today's checklist

On a normal day you don't edit anything — you just open the page and tick steps as you do them. The progress card shows `3/5 tasks done` and the time card shows how many minutes you've completed against the routine's total, so you can see at a glance whether you're on pace.

### Tightening the routine over time

If a step never gets done, reorder it or remove it. If mornings feel rushed, trim a task's minutes or drop it entirely. Because the routine is a single editable list, evolving it is a 10-second change in edit mode — not a rebuild.

## How to use it

1. Open the **Morning Routine** page from the sidebar (or in the [live app](https://habitforge.aoneahsan.com)).
2. If you don't have a routine yet, give it a name (for example "Weekday Morning") and create it.
3. Click **Edit**, then **Add Task**. Enter a **Task Name** and a **Duration** in minutes (1–120). Repeat for each step.
4. Use the up/down controls in edit mode to reorder steps, or the delete control to remove one.
5. Click **Done Editing** to switch to run mode.
6. Each morning, tick a step's checkbox as you complete it. The progress and time cards update live.
7. When every step is checked, the page shows a "Morning routine complete!" celebration.
8. To start the day's checklist over, use **Reset** — it clears today's progress without changing the routine.

## FAQ

### Can I have more than one routine?

The page works around a single default routine — the one it shows and runs each day. You give it a name when you create it and build all your morning steps inside that one ordered list. Think of it as your morning, not a library of routines.

### Does my progress carry over to the next day?

No, and that's intentional. Today's checked steps are recorded against today only. Tomorrow the routine resets to all-unchecked so you can run it fresh. Past days remain logged; the **Reset** button only affects the current day.

### What are the time estimates for?

Each task carries a duration in minutes, and the page sums them into a total and shows how many minutes you've completed. It's a planning and pacing aid — "this routine is about 25 minutes" — not a live timer or alarm.

### How is this different from the to-do list?

The [to-do list](./todo) is for one-off tasks with priorities and due dates. The morning routine is a fixed, ordered sequence you repeat every day and run as a checklist. Different jobs: tasks get done once, the routine runs daily.

### Should routine steps also be habits?

They can be. A routine is great for the in-the-moment sequence, while a [habit](../habits/create) gives a single behaviour its own streak and strength over months. Many people keep the routine as the morning script and promote one or two key steps to standalone habits.

### Is it saved across devices?

Yes. Your routine and each day's completion log save to your account and sync across web and mobile through Firestore. See [Account basics](../getting-started/account-basics).

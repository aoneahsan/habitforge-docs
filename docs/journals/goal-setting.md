# Goal setting with milestones and progress

**The HabitForge goals screen lets you set goals, break each into milestones, and track progress as a percentage of milestones checked off.** Create a goal with a title, optional description, category, priority, and a target date. Each goal gets a progress bar, a days-remaining (or overdue) countdown, and a milestone checklist. As you tick milestones, the bar fills and the percentage updates automatically; when every milestone is done, the goal moves itself to **Completed**. Goals are organised under Active, Completed, and All tabs with live counts. It is a straightforward, free planner — no premium tiers, no fabricated "success scores".

## Use cases

### Turning a vague intention into a plan

"Get fit" is not actionable; a goal with milestones is. Create the goal, set a realistic target date, then add milestones like `Walk 3x this week`, `Hit the gym twice`, and `Run 5k`. Checking them off is what moves the bar — progress reflects real steps, not a guess.

### Keeping deadlines honest

Each goal shows days remaining, and overdue goals turn red with a "X days overdue" label. That visible countdown is a gentle pressure to either do the work or move the date deliberately rather than letting it slip silently.

### Sorting what matters most

Category and priority (high/medium/low) badges let you scan a list of goals and see at a glance which are urgent. Use the **Active** tab as your working list and the **Completed** tab as a record of what you have already achieved.

## How to use it

1. Open goals at [habitforge.aoneahsan.com/goals](https://habitforge.aoneahsan.com/goals) while signed in.
2. Press **New Goal**, then fill in the title (required), an optional description, a category, a priority, and a **target date** (required). Press **Create Goal**.
3. On the goal card, type a milestone in **Add a milestone…** and press Enter or **Add**. Repeat for each step.
4. Tick a milestone's checkbox as you finish it — the progress bar and percentage update right away.
5. When all milestones are checked, the goal automatically moves to the **Completed** tab.
6. Switch between **Active**, **Completed**, and **All** tabs to filter your goals.

## FAQ

### How is progress calculated?

Progress is purely the share of milestones you have checked off — completed milestones ÷ total milestones, as a percentage. There is no separate manual progress slider; ticking milestones is the only way the bar moves.

### Can a goal reach 100% without milestones?

Not through this screen. Because completion is driven by checking off milestones, a goal with no milestones stays Active at 0%. To finish a goal, add at least one milestone and check it off (when the last one is checked, the goal completes itself).

### Can I link a goal to my habits?

Goals stand on their own in this screen. The underlying data supports linking habits to a goal, but there is no button to attach habits from the goal UI yet. For now, run the habit in the [Habits](../habits/create) section and use a goal to track the larger milestone-based outcome.

### Can I edit or delete a goal after creating it?

You can add milestones and check them off, and a goal auto-completes when fully done. This screen does not currently offer a delete or full edit of an existing goal, so set the title, category, priority, and date thoughtfully when you create it.

### What does the target date do?

It drives the days-remaining countdown and the overdue warning. It does not lock or auto-fail the goal — an overdue goal simply shows a red "overdue" label until you complete it or, in a future update, adjust it.

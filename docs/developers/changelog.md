# Developer changelog

Every change to the API, the MCP connection, webhooks and the calendar feed, newest first. The API's version is
part of its address, `/v1`; the [OpenAPI file](./api.md#where-is-the-full-reference) always describes the version
it sits under.

## 20 November 2026

- Access keys under Settings → Other apps, the `/v1` API with its OpenAPI file, the MCP connection for AI
  assistants, webhooks for habits, check-ins, pauses and achievements, the calendar feed of habit days and
  challenge dates, and two-step sign-in under Settings → Security.
- Households, friends and challenges can be read, never changed, from outside HabitForge.
